# Greeshma B — React Portfolio

A modern dark-themed responsive portfolio starter built with React, Vite, Tailwind CSS v4, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract this project and open its folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Customize before publishing

Search the project for these placeholders and replace them:

- `your.email@example.com` — your real email address (used by the contact links and mailto form).
- `https://github.com/` — your GitHub profile and individual project repository URLs.
- `https://linkedin.com/` — your LinkedIn profile.
- `Your Project One`, `Your Project Two`, `Your Project Three` — your real project names, descriptions, tech stacks, and links.
- Edit the skills array in `src/App.jsx` to match your actual experience.
- Replace the GB initials card with your profile photo if you want one.

## Production build

```bash

npm run build
npm run preview
```

The production-ready static site is generated in `dist/`.
